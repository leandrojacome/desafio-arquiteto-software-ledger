# 09 Qualidade

Como se sabe que o ledger faz o que a documentação diz. A [estratégia de testes](estrategia-de-testes.md) explica o que cada camada prova e como rodá-la, e os [testes de concorrência e de falha](testes-de-concorrencia-e-falha.md) detalham os cenários que mais pesam num ledger. As [garantias automáticas](portoes-de-qualidade.md) reúnem o que o build e os testes de arquitetura barram antes de qualquer outro teste, e os [limites conhecidos](limites-conhecidos.md) dizem o que ainda não foi medido nem exercitado.
